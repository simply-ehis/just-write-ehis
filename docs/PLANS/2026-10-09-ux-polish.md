# UX Polish Build Plan (2026-10-09)

Survey-driven plan. Four explore surveys (Inbox/capture, AI panel, voice/audio, writing feel + reader) produced the debt map below. User approved starting **Phase 1 then Phase 2**.

## Open decisions (not blocking Phase 1–2)
1. **Inbox rename target:** propose label **"Capture"** (id stays `inbox` — no data migration; matches the existing "Capture" nav group on mobile). Alternative: "Inbox — Capture".
2. **Capture shortcut:** Ctrl+J is currently the AI panel toggle. Proposal: **Ctrl+Shift+E** for Quick Capture, keep Ctrl+J on AI panel. Alternative: capture gets Ctrl+J, AI panel moves to Ctrl+Shift+J.

## Execution order
**Phase 1 → 2 → 4 → 5 → 3 → 6 → 7.** Phase 1 = trust bugs (small, high impact); Phase 2 = Inbox/Capture discoverability (the direct ask); Phase 4 = writing feel; Phases 5/3/6 = polish layers.
